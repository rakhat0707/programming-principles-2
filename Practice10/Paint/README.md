# Paint Application (Pygame)

## Features
- Free drawing mode
- Draw rectangles
- Draw circles
- Eraser tool
- Color selection

## Controls
- P — draw mode
- R — rectangle
- C — circle
- E — eraser

- 1 — black
- 2 — red
- 3 — green
- 4 — blue

## How to Run
```bash
cd Practice10/Paint
python main.py
