# TSIS2 — Paint (Short Guide)

## 🚀 Запуск

```bash
cd TSIS/TSIS2
python paint.py
```

---

## 🎨 Управление

* **P** — Pencil
* **L** — Line
* **R** — Rectangle
* **C** — Circle
* **S** — Square
* **T** — Triangle
* **H** — Rhombus
* **E** — Eraser
* **F** — Fill
* **Y** — Text

---

## 📏 Размер кисти

* **1** — маленький
* **2** — средний
* **3** — большой

---

## ✏️ Использование

* Pencil → зажать мышку и рисовать
* Line → клик → тянуть → отпустить
* Shapes → зажать → отпустить
* Fill → клик по области
* Text → Y → клик → писать → Enter

---

## 💾 Сохранение

```
Ctrl + S
```
