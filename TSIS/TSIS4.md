# TSIS4 — Snake Game (Short Guide)

## 🚀 Запуск

```bash
cd TSIS/TSIS4
python main.py
```

---

## 🎮 Управление

* ↑ ↓ ← → — движение
* Esc — выход

---

## 🧪 Использование

* собирать еду
* избегать стен, себя и препятствий
* уровень увеличивается → скорость растёт

---

## 🍎 Еда

* обычная — даёт очки
* разный вес
* исчезает по таймеру

---

## ☠️ Poison

* уменьшает змейку
* если длина ≤ 1 → game over

---

## ⚡ Power-ups

* Speed — ускорение
* Slow — замедление
* Shield — защита

---

## 🧱 Obstacles

* появляются с 3 уровня
* столкновение = game over

---

## 🗄️ База данных

* ввод username
* сохранение результата
* leaderboard (Top 10)
* personal best
