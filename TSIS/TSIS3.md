# TSIS3 — Racer Game (Short Guide)

## 🚀 Запуск

```bash
cd TSIS/TSIS3
python main.py
```

---

## 🎮 Управление

* ← → — движение машины
* Esc — выход

---

## 🧪 Использование

* избегать машин и препятствий
* собирать монеты
* подбирать power-ups

---

## ⚡ Power-ups

* Nitro — ускорение
* Shield — защита от 1 столкновения
* Repair — восстановление

---

## 📊 Интерфейс

* счёт (score)
* дистанция
* количество монет
* активный power-up

---

## 📁 Дополнительно

* leaderboard сохраняется в `leaderboard.json`
* настройки — `settings.json`

* Main Menu
