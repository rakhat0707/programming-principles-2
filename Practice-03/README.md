# Practice 3: Python Functions and Object-Oriented Programming

## Overview
This practice is focused on improving skills in Python functions, lambda expressions,
and Object-Oriented Programming (OOP).  
The goal is to learn how to write reusable code, apply anonymous functions,
and build classes with inheritance.

---

## Learning Objectives
By completing this practice, I learned how to:

- Define and call Python functions
- Use different types of arguments (positional, default, *args, **kwargs)
- Return values from functions
- Apply lambda expressions with `map()`, `filter()`, and `sorted()`
- Create classes, objects, and methods
- Work with class variables and instance variables
- Implement inheritance using `super()`
- Override methods in child classes
- Organize Python code into a clear project structure
