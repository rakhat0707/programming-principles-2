# Practice2 – Python Control Flow

This repository contains Python examples based on the W3Schools Python Tutorial.
The practice focuses on Python control flow concepts from Boolean values to loops.

## Topics Covered
- Boolean Values
- Booleans as Comparison Results
- Boolean Operators
- If Statement
- If Else
- If Elif Else
- Short Hand If Else
- While Loops
- While Loop Break
- While Loop Continue
- For Loops
- For Loop Break
- For Loop Continue
